# Kontrollmatrix (öffentliche Fassung)

> Erzeugt aus dem internen Register `docs/compliance/kontrollmatrix.toml` mit `scanview-nachweise register darstellen` — nicht von Hand bearbeiten.

Je Anforderung: Anwendbarkeit, Prüfhandlung und Sollwert; die Spalte „Ergebnis“ trägt je Release die Nachweis-ID aus dem signierten Release-Manifest. „offen bis …“ ist zulässig und prüffähig, erfüllt aber keine Release-Voraussetzung. Die ISO-27001-Spalte ist nur eine Zuordnung, keine eigene Prüfung.

Art: `pflicht` = rechtliche Anforderung (hier: behandelt, als gälte sie), `freiwillig` = selbst gewählter Maßstab, `kunde` = Kundenanforderung.

Zeilen mit „intern (Vault), auf Anfrage“ enthalten sicherheitsrelevante Prüfdetails; sie liegen in der internen Dokumentation und werden Prüfern auf Anfrage vorgelegt.

Geplante Maßnahmen, deren Bezeichnung allein Rückschlüsse auf den Betrieb zuließe, stehen nur in der internen Fassung; sie werden Prüfern ebenfalls auf Anfrage vorgelegt.
